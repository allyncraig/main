# Interactive Sermon Preparation Tool

## How to Access

### Mobile App

Download [Android APK](downloads/ISPT.apk) - direct install if accessing from an Android device. Current Version: 1.0.0

### PWA App

For iOS there is also a <a class="action-link" href="./pwa/ISPT/" target="_blank" rel="noopener">PWA</a> (Progressive Web App). See [PWA Install Instructions](pwa_install_instructions.md) for how to install this on an iOS device.

---

## Notes

The Android APK can be installed directly on compatible devices. You may need to enable installation from unknown sources.
